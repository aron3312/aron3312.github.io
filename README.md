# Piper Puzzles

Website for Piper Puzzles games: landing page, privacy policy and support page for 魔笛鼠鼠回家囉 / Hamelin Squeaks (`hamelin/`) and 卡舖人生 / Card Shop Life (`cardshop/`), and `app-ads.txt` for AdMob (one AdMob account, shared by both apps).

Static HTML served by GitHub Pages from `master` (no build step).
